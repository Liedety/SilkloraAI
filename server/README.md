# SilkloraAI Local AI Hub (PC Server)

Компактный сервер для компьютера на Windows и Linux, позволяющий запускать локальные GGUF-модели (ролевой отыгрыш и Vision мультимодальность с `mmproj`) и подключать мобильное приложение **SilkloraAI** по локальной сети Wi-Fi.

---

## Возможности

* 🖥️ **Простой и красивый Web-интерфейс**: панель управления открывается в браузере сразу при запуске сервера (`http://localhost:8080`).
* 📡 **Подключение по Wi-Fi**: сервер слушает `0.0.0.0:8080`, автоматически определяет локальный IP ПК в вашей домашней сети и показывает готовый адрес для ввода на телефоне (например, `http://192.168.1.55:8080/v1`) с QR-кодом.
* 🤗 **Загрузка любых моделей с HuggingFace**: введите ID любого репозитория (например, `bartowski/Llama-3.2-3B-Instruct-GGUF` или `Qwen/Qwen2.5-7B-Instruct-GGUF`) — сервер покажет доступные квантовки и скачает нужную в один клик.
* 👁️ **Поддержка текста и Vision (мультимодальность)**: поддержка текстовых моделей для ролевого отыгрыша и мультимодальных проекторов `mmproj-*.gguf` для анализа фотографий и аватаров.
* 🔒 **Выбор активной модели СТРОГО на ПК**: телефон не выбирает модели, а сразу подключается к той модели, которую вы активировали на компьютере.
* ⚡ **OpenAI-совместимый API**: поддержка стриминга SSE (`/v1/chat/completions`) и проверки статуса (`/v1/models`).

## Быстрый запуск

### Windows
1. Убедитесь, что установлен [Python 3.10+](https://www.python.org/downloads/) (с галочкой *"Add Python to PATH"*).
2. Запустите двойным кликом файл:
   ```cmd
   start-server.bat
   ```
3. Скрипт автоматически создаст изолированное окружение `venv`, установит зависимости и откроет веб-панель в браузере.

### Linux / macOS
1. Сделайте скрипт исполняемым и запустите:
   ```bash
   ./start-server.sh
   ```
2. Откроется веб-панель управления `http://localhost:8080`.

## Включение аппаратного ускорения (GPU)

По умолчанию сервер запускается на CPU. Чтобы задействовать видеокарту на полную мощность (NVidia CUDA / Apple Metal):

### NVIDIA GPU (Windows):
```cmd
call venv\Scripts\activate
set CMAKE_ARGS=-DGGML_CUDA=on
pip install llama-cpp-python --force-reinstall --no-cache-dir --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu121
```

### NVIDIA GPU (Linux):
```bash
source venv/bin/activate
CMAKE_ARGS="-DGGML_CUDA=on" pip install llama-cpp-python --force-reinstall --no-cache-dir
```

## Подключение в мобильном приложении SilkloraAI

1. Откройте приложение **SilkloraAI** на телефоне.
2. Перейдите во вкладку **Настройки**.
3. В самом верху переключите режим на **[ 🖥️ Локальный ИИ (ПК / Сервер) ]**.
4. Введите адрес вашего ПК (показан в веб-панели сервера, например: `http://192.168.1.55:8080/v1`).
5. Нажмите кнопку **«Проверить подключение» (Ping)**.
6. При успешном подключении загорится зеленый индикатор с измеренным пингом, и телефон начнет работать с вашей моделью на компьютере!
