Phone cannot connect? (Windows Firewall Rule)

Windows Firewall often blocks incoming port 8080 on Wi-Fi by default. If your phone cannot connect, run this command in Administrator PowerShell/CMD:

netsh advfirewall firewall add rule name="SilkloraAI Local Hub" dir=in action=allow protocol=TCP localport=8080 profile=any
