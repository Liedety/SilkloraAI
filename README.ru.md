# SilkloraAI

Локальный мобильный клиент для ролевого общения с ИИ на Android (и в современных браузерах), дополненный автономным сервером для ПК (**Silklora Local AI Hub**) для запуска локальных GGUF-моделей по Wi-Fi.

SilkloraAI поддерживает:
- **Локальный сервер на ПК:** встроенный **Silklora Local AI Hub** (`server/`) с автоматической установкой и подключением по QR-коду, а также Ollama, LM Studio, KoboldCpp, vLLM и любой OpenAI-совместимый API.
- **Облачные API:** OpenRouter, Groq, Together AI, Mistral, OpenAI и др.

---

## Основные возможности

- **Silklora Local AI Hub (`server/`):** автономный ПК-сервер для Windows, Linux и macOS с автоустановкой Python и движка (CUDA, Metal, CPU), подбором GGUF-моделей с Hugging Face под характеристики вашего железа, докачкой файлов, связкой моделей зрения (`mmproj`) и веб-панелью с QR-кодом.
- **Персонажи, групповые чаты и эмоции:** карточки с лором и приветствиями, статичный аватар и отдельные спрайты эмоций под сообщениями с проверкой тегов.
- **Маршрутизация ИИ по функциям и Vision:** раздельный выбор (ПК или облако) для ролевого чата, волшебной палочки, графа памяти, пересказов, генераторов персонажей/групп и анализа изображений.
- **Интерактивный граф памяти и оптимизация длинных чатов:** граф фактов и отношений с фиксацией узлов, стабильный префикс промпта для KV-кэша, окно реплик по токен-бюджету и пакетное сжатие истории.
- **Локальность и приватность:** все персонажи, персоны, сообщения и граф памяти хранятся только на вашем устройстве в IndexedDB.
- **Гибкий интерфейс и два языка:** 4 вкладки настроек, тема «Графит» и кастомные палитры, стили текста и полная поддержка русского и английского языков.

## Быстрый старт (v2.0.0)

### 1. Приложение для Android
1. Скачайте `silklora-ai.apk` в разделе [Releases](../../releases).
2. Установите APK на устройство Android.
3. Укажите облачный API-ключ или отсканируйте QR-код локального ПК-сервера в разделе **Настройки -> ИИ и подключение**.

### 2. Локальный сервер для ПК (`server.zip`)
1. Скачайте `server.zip` в разделе [Releases](../../releases) (или возьмите папку `server/` из репозитория) и распакуйте архив на ПК.
2. Запустите `start-server.bat` (Windows) или `./start-server.sh` (Linux / macOS).
3. При первом запуске скрипт сам установит Python 3.12 (если его нет), зависимости и движок под вашу видеокарту или процессор, после чего откроет панель управления на `http://localhost:8080`.
4. Скачайте подходящую GGUF-модель во вкладке **Модели**, загрузите ее и отсканируйте QR-код с телефона.

Подробные параметры сервера и решение проблем описаны в [`server/README.md`](server/README.md).

## Локальная разработка и сборка

### Требования
- Node.js 18+
- JDK 17
- Android SDK (платформа `android-34`)
- Python 3.10–3.13 (опционально, для запуска тестов сервера)

### Запуск в браузере и тесты
```bash
npm install
npm test
npm run dev
```

### Сборка Android APK
```bash
./build-apk.sh
```
