# SilkloraAI — Архитектурный гид и спецификация проекта

**SilkloraAI** — автономное локальное мобильное приложение для ролевого отыгрыша (Roleplay) с искусственным интеллектом, динамической памятью (Knowledge Memory Graph), поддержкой одиночных и групповых чатов, эмоций персонажей, мультимодального зрения (Vision), компиляцией в Android APK и публикацией релизов на GitHub.

## 2. Ключевые архитектурные модули

### 2.1. Локальное хранилище данных (`Dexie.js`)
Приложение полностью автономно и работает без внешних бэкендов:
- **`characters`**: Персонажи (имя, описание, аватар, сдвиг кроппера, фон чата, реплика, папка, эмоции `emotions: { emotion: string, avatar?: string }[]`).
- **`folders`**: Папки для группировки персонажей с возможностью создания и удаления.
- **`groups`**: Группы ролевой вселенной (название, сеттинг, правила мира, предыстория, роли персонажей `characterRoles: Record<string, string>`, аватар, фон).
- **`chats`**: Сессии переписки (одиночные и групповые, привязка персоны игрока, тумблер мыслей, директивы, шкалы отношений `relationships: Record<string, number>`).
- **`messages`**: Сообщения с массивом вариантов `variants: { text, thought, emotion, timestamp }[]` для карусели `< 1 / 5 >`.
- **`memoryNodes` / `memoryEdges`**: Узлы и связи графа памяти.
- **`apiKeys`**: Многоключевой менеджер провайдеров.
- **`settings`**: Язык, активные модели, стили и цветовая тема.

---

### 2.2. Граф долгосрочной памяти (Memory Knowledge Graph)
- Визуализация на базе HTML5 Canvas с физической симуляцией (отталкивание узлов Кулона, пружинные связи Гука, центрирование).
- Плавный зум (масштабирование), перемещение (pan) и просмотр детальной карточки узла.
- Перетаскивание и фиксация положения узлов (node pinning).
- Цветовая дифференциация узлов:
  - **События (Event)** — янтарный
  - **Отношения (Bond)** — розовый
  - **Факты (Fact)** — небесно-голубой
  - **Локации (Location)** — изумрудный
  - **Секреты (Secret)** — фиолетовый
- Фоновый анализ `extractMemoryAndAffinity` после каждого ответа бота.

---

### 2.3. AI Engine и ролевой отыгрыш
1. **Поддержка провайдеров**: OpenRouter, OpenAI, Anthropic (Claude), Gemini, Groq, DeepSeek, Custom URL (Ollama, LM Studio, KoboldCpp).
2. **Литературный Uncensored 18+ Промптинг**:
   - Жесткие системные инструкции для удержания характера без лекций и морализаторства.
   - Исключение шаблонных клише ИИ и утечек мета-информации.
   - Чистота языка общения (исключение внезапных англоязычных вставок).
   - Оформление действий в `*звездочки*` с отдельной подсветкой.
   - Блок скрытых мыслей `<thought>...</thought>` (отключен по умолчанию).
   - Строгая изоляция говорящего в группе (`CRITICAL GROUP CHAT SPEAKER IDENTITY`).
3. **Мультимодальность (Vision)**:
   - Прикрепление фото в чате и генераторе персонажей.
   - Фильтрация и поиск Vision-моделей.

---

### 2.4. Чат и манипуляции с историей
- **Откат (`Rollback`)**: Создает новую ветку диалога (Fork), не уничтожая исходный чат.
- **Редактирование**:
  - Редактирование реплики игрока удаляет последующие сообщения и автоматически вызывает новый ответ бота.
  - Редактирование реплики бота сохраняется прямо в выбранном варианте.
- **Карусель вариантов (`< 1 / 5 >`)**: Перелистывание альтернативных ответов без потери предыдущих генераций.
- **Волшебная палочка (Magic Wand)**:
  - Для игрока: ghostwriter-генерация реплики (включая автономное продолжение при пустом вводе).
  - Для бота: guided regeneration (направление ответа, например «сделай агрессивнее»).
- **Слеш-команды (`/`)**: `/continue`, `/summary`, `/action`, `/memory`, `/reset`.
- **Поле ввода**: Автоматически расширяемый textarea для комфортного ввода больших объемов текста.

## 3. Архитектура иконки приложения

Фирменная иконка представляет собой монохромный пиксельный логотип с буквой «S» на черном фоне:
- **Геометрия**: макро-сетка 8x8 клеток, каждая клетка — блок 4x4 пикселя (активные координаты: `(3,1)-(5,1)`, `(2,2)`, `(3,3)-(4,3)`, `(5,4)-(5,5)`, `(2,6)-(4,6)`).
- **Адаптивные иконки Android (API 26+)**:
  - Фон (`ic_launcher_background.xml`): чистый черный `#000000`.
  - Передний план (`ic_launcher_foreground.png`): отцентрированный белый логотип в безопасной зоне 72dp из 108dp (mdpi: 108px, hdpi: 162px, xhdpi: 216px, xxhdpi: 324px, xxxhdpi: 432px).
- **Классические иконки (Legacy)**:
  - `ic_launcher.png` (квадрат с черным фоном) и `ic_launcher_round.png` (круг с черным фоном) по плотностям: 48, 72, 96, 144, 192 px.
- **Веб-ассеты**: `public/icon.png` (512x512) и `public/favicon.ico`.

## 6. Особенности релиза v1.0.0
1. **Фирменная иконка**: Pixel-art логотип «S» на глубоком черном фоне встроен во все ресурсы Android (`mipmap-mdpi` .. `mipmap-xxxhdpi`) и веб-бандл.
2. **Ветка релизов и релиз 1.0.0 на GitHub**:
   - Создана ветка `release`, тег `v1.0.0`, официальный релиз на GitHub с прикрепленным установочным APK (`silklora-ai.apk`).
   - Подготовлен понятный англоязычный `README.md` с указанием авторства и лицензией MIT.
3. **Групповые чаты и изоляция персонажей**:
   - Строгая изоляция участников группы — бот больше не говорит от лица других персонажей.
   - Исключена выбранная персона игрока из списка доступных ботов для вызова.
   - История группы формируется со строгим чередованием ходов `user`/`assistant`, устраняя ошибки провайдеров API.
4. **Спрайты эмоций без искажения аватарок**:
   - Аватарка персонажа в шапке и сообщениях остается нетронутой.
   - Выбранная эмоция отображается отдельной карточкой иллюстрации снизу под репликой.
5. **Чистота языка и соблюдение лимитов**:
   - Исключены внезапные переключения языка посреди реплики.
   - Точные лимиты абзацев соблюдаются моделью даже при объемных генерациях.
6. **Оптимизация стабильности**:
   - Устранен токен остановки `<|begin_of_sentence|>`, из-за которого происходили сбросы и зависания ответов.
   - Мысли персонажа отключены по умолчанию и активируются по желанию пользователя.
